## Sticker Boarder Maker
A little boarder maker which runs with powershell. It's a little ugly, but it works. You select a photo from files, and select a boarder size (in pixels), and then press the generate button. The final sticker will show up in the same folder as the boardermaker. First python project! :3

To use you download it and open in powershell using "cd (path to the folder it's in)", return, and then "python BoarderMaker.py", return, and it opens.
