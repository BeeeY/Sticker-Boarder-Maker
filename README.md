## Sticker Boarder Maker
A little boarder maker which runs with powershell. It's a little ugly, but it works. You select a photo from files, and select a boarder size (in pixels), and then press the generate button. The final sticker will show up in the same folder as the boardermaker. First python project! :3

## Setup
1.Install Python 3 and download the boarder maker
2.Run pip install pillow on powershell
3.Run "cd (path to the folder it's in)"
4.Run "python BoarderMaker.py" and it will open

## How to Run
1. Pick a photo
2. Set boarder size in pixels
3. Click generate, the new image will be in the same folder as the boarder maker
